# Data Scope

## Domain

The active domain is telecom and networking manufacturing: radio, baseband, transport, routing, switching, optical, access, Wi-Fi, fixed-wireless, power, and their child PCB/RF/optical modules.

Erivon is fictional. `ERV_*` identifiers are synthetic. Real EMS and equipment-manufacturer names may be retained as sourced educational references only; all site capabilities, products, volumes, routes, assignments, and performance are synthetic.

## Dates

| Record class | Inclusive range |
|---|---|
| Actual and execution | 2023-01-01 through 2026-10-31 |
| Forecast | 2026-11-01 through 2027-12-31 |

Configured planning snapshots are dated 2025-10-31 and 2026-10-31. Each snapshot sees actuals only through its as-of date; later periods remain forecasts.

## Catalog scope

The `local_16gb` configuration defines provisional maximums for active sites, products, tests, resources, routes, assignments, rows, bytes, memory, disk, and wall time. These are refusal gates, not verified active counts or achieved performance.

Sparse qualified combinations are required. The generator must not create every site × product × test Cartesian combination.

## Synthetic contracts

- Four explicit demand types
- Effective-dated BOM and sourcing
- Parent and made-child routes
- Seven equipment-capacity behaviors
- Single-DUT and multi-DUT configurations
- Named, auditable Raw noise
- Validation and promotion manifests

No dataset totals, distributions, model scores, or output counts are documented until a specific promoted run is measured and identified by run ID.
